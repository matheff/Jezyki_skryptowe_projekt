## Opis Wyzwania
<p class="editor-paragraph mb-2" dir="ltr"><span style="white-space: pre-wrap;">Zaimplementuj pierwszy etap konsolowej aplikacji do zarządzania i analizy danych sprzedażowych. Aplikacja musi wczytywać dane z pliku w autorskim formacie </span><b><strong class="editor-text-bold font-bold" style="white-space: pre-wrap;">SDF</strong></b><span style="white-space: pre-wrap;"> (Sales Data Format), walidować je, przechowywać w strukturach obiektowych i generować raporty zapisywane do pliku.</span></p><p class="editor-paragraph mb-2" dir="ltr"><span style="white-space: pre-wrap;">Projekt jest zaprojektowany z myślą o dalszym rozszerzaniu — w kolejnych etapach zostanie dodana obsługa bazy danych, eksport do wielu formatów i panel analityczny.</span></p>
